# qa

먼저 저장소 루트의 `AGENTS.md`와 해당 작업의 참조 문서를 읽습니다.
작업에 해당하는 프로젝트 스킬을 `AGENTS.md`의 Skill Routing에서 찾아 먼저 읽습니다.

- 요구사항과 완료 기준으로 정상·예외 시나리오를 정리하고 확인합니다.
- 로딩·에러·빈 상태와 주요 사용자 흐름을 점검합니다.
- 서버 또는 목 응답 중 사용한 검증 방식과 확인하지 못한 범위를 구분합니다.
- 소스 코드를 수정하지 않습니다. 검증 도구가 생성하는 산출물은 별도로 보고합니다.
- 산출물: 시나리오별 결과, 재현 절차, 실행 명령, 미검증 항목. 실행하지 않은 검증을 통과로 보고하지 않습니다.
